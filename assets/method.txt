We propose STEER, a framework that steers a frozen video diffusion model to perform accurate video text rewriting by injecting decomposed glyph and style guidance.
Given a source video, mask video, source text, and target text, we construct a reference image by cropping the first source frame using the first mask frame. A style encoder extracts source style, while a glyph encoder obtains dual-granularity glyph representations from the target text. These conditions are injected via cross-attention into a Text Control Adapter, enabling precise style-preserving text editing. We also introduce an OCR-guided region reweighting loss to enhance editing on long texts and small regions.
